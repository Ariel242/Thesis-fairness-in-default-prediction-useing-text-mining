# Outputs Documentation

All modeling outputs are saved to `results/walk_forward/`. They are generated by `analysis/preliminary_results_cloude.py` at the end of the walk-forward run.

Each row in the per-fold files represents one combination of: fold × model × variant (× threshold where applicable).

**Models:** `Logistic`, `XGBoost`
**Variants:** `Structured`, `Structured+Text`
**Thresholds:** `0.5`, `0.6`, `0.7`

---

## Per-Fold Files

### `wf_predictive_folds.csv`
Predictive metrics for every fold, with 95% bootstrap confidence intervals.

| Column | Description |
|--------|-------------|
| `fold` | Fold index (1-based) |
| `train_cutoff` | Last month included in training set |
| `test_end` | Last month included in test set |
| `n_train` | Number of training observations |
| `n_test` | Number of test observations |
| `n_defaults` | Number of defaults in test set |
| `Model` | `Logistic` or `XGBoost` |
| `Variant` | `Structured` or `Structured+Text` |
| `AUC` | ROC-AUC |
| `AUC_CI_lo/hi` | 95% bootstrap CI for AUC |
| `PR_AUC` | Precision-Recall AUC |
| `PR_AUC_CI_lo/hi` | 95% bootstrap CI for PR-AUC |
| `Brier` | Brier score (lower = better calibration) |
| `Brier_CI_lo/hi` | 95% bootstrap CI for Brier |
| `GINI` | Gini coefficient (= 2×AUC − 1) |

**Shape:** 56 rows (14 folds × 2 models × 2 variants)

---

### `wf_fairness_folds.csv`
Fairness gaps across ZIP3 groups, per fold and threshold.

| Column | Description |
|--------|-------------|
| `fold` | Fold index |
| `train_cutoff` | Last training month |
| `test_end` | Last test month |
| `Model` | `Logistic` or `XGBoost` |
| `Variant` | `Structured` or `Structured+Text` |
| `threshold` | Decision threshold (0.5 / 0.6 / 0.7) |
| `FNR_gap` | Max − Min False Negative Rate across ZIP3 groups |
| `FPR_gap` | Max − Min False Positive Rate across ZIP3 groups |
| `Brier_gap` | Max − Min Brier Score across ZIP3 groups |
| `n_groups` | Number of ZIP3 groups that passed the minimum size filters |

**Note:** NaN values appear in early folds where no ZIP3 group meets the minimum thresholds (`MIN_GROUP_N=100`, `MIN_GROUP_POS=10`).

**Shape:** 168 rows (14 folds × 2 models × 2 variants × 3 thresholds)

---

### `wf_delong.csv`
DeLong statistical test comparing AUC of Structured vs. Structured+Text, per fold and model.

| Column | Description |
|--------|-------------|
| `fold` | Fold index |
| `Model` | `Logistic` or `XGBoost` |
| `AUC_Structured` | AUC of the structured-only model |
| `AUC_Structured+Text` | AUC of the text-augmented model |
| `Delta_AUC` | Difference: Structured − Structured+Text |
| `Z_stat` | DeLong Z-statistic |
| `p_value` | Two-sided p-value |
| `CI_95_lo/hi` | 95% CI around Delta_AUC |

**Shape:** 28 rows (14 folds × 2 models)

---

### `wf_all_folds.csv`
Combined file merging predictive and fairness metrics (without bootstrap CIs). Useful for joint analysis.

**Shape:** 168 rows — same structure as `wf_fairness_folds.csv` with predictive metrics added.

---

## Summary Files

### `wf_predictive_summary.csv`
Mean ± std of predictive metrics across all folds, by model and variant.

| Column | Description |
|--------|-------------|
| `Model` | `Logistic` or `XGBoost` |
| `Variant` | `Structured` or `Structured+Text` |
| `AUC` (mean) / `AUC.1` (std) | ROC-AUC summary |
| `PR_AUC` / `PR_AUC.1` | PR-AUC summary |
| `Brier` / `Brier.1` | Brier score summary |
| `GINI` / `GINI.1` | Gini summary |

**Shape:** 4 data rows (2 models × 2 variants)

---

### `wf_summary.csv`
Combined summary of both predictive and fairness metrics (at default threshold 0.5). The main results table.

Includes all columns from `wf_predictive_summary.csv` plus:

| Column | Description |
|--------|-------------|
| `FNR_gap` / `FNR_gap.1` | Mean ± std of FNR gap across folds |
| `FPR_gap` / `FPR_gap.1` | Mean ± std of FPR gap across folds |
| `Brier_gap` / `Brier_gap.1` | Mean ± std of Brier gap across folds |

**Shape:** 4 data rows (2 models × 2 variants)

---

### `wf_fairness_summary_thr05/06/07.csv`
Same as `wf_summary.csv` for fairness metrics, split by threshold (0.5 / 0.6 / 0.7).

**Shape:** 4 data rows per file

---

### `wf_delta_summary.csv`
Mean ± std of the metric **change** from adding text (Structured+Text − Structured), per model.

| Column | Description |
|--------|-------------|
| `Model` | `Logistic` or `XGBoost` |
| `Δ_AUC` / `Δ_AUC.1` | Mean ± std change in AUC |
| `Δ_PR_AUC` / `Δ_PR_AUC.1` | Mean ± std change in PR-AUC |
| `Δ_Brier` / `Δ_Brier.1` | Mean ± std change in Brier |
| `Δ_GINI` / `Δ_GINI.1` | Mean ± std change in Gini |

**Current values:**

| Model | Δ_AUC (mean) | Δ_PR_AUC (mean) | Δ_Brier (mean) |
|-------|-------------|----------------|---------------|
| Logistic | −0.0008 | −0.0015 | +0.0009 |
| XGBoost | −0.0004 | +0.0023 | +0.0019 |

**Shape:** 2 data rows

---

### `wf_group_coverage.csv`
Per fold, how many ZIP3 groups survived the fairness filter (`MIN_GROUP_N`, `MIN_GROUP_POS`).

| Column | Description |
|--------|-------------|
| `Model` | Model name |
| `Variant` | Feature variant |
| `threshold` | Decision threshold |
| `n_candidate_groups` | Average ZIP3 groups in test fold |
| `n_pass_n_threshold` | Average groups passing `MIN_GROUP_N` |
| `n_pass_pos_threshold` | Average groups passing `MIN_GROUP_POS` |
| `n_included` | Average groups included in fairness calculation |

**Shape:** 12 rows (2 models × 2 variants × 3 thresholds)

---

### `wf_zip_summary.csv`
Per-ZIP3 performance summary, averaged across folds in which that ZIP3 appeared.

| Column | Description |
|--------|-------------|
| `zip3` | 3-digit ZIP prefix |
| `Model` | Model name |
| `Variant` | Feature variant |
| `n_folds` | Number of folds this ZIP3 appeared in |
| `n_total` | Total observations across folds |
| `n_default` | Total defaults across folds |
| `AUC_mean` | Mean AUC for this ZIP3 |
| `FNR_mean` | Mean False Negative Rate |
| `FPR_mean` | Mean False Positive Rate |
| `Brier_mean` | Mean Brier Score |
| `default_rate` | Overall default rate for this ZIP3 |

**Shape:** 64 rows (16 ZIP3s × 2 models × 2 variants)
